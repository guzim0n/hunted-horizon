# Hunted Horizon
## About
Hunted Horizon is a pixel‑art 2D platformer developed as part of my 2025 A‑Level Computer Science NEA project.
The game draws inspiration from titles like Sackboy: A Big Adventure and Death’s Door, particularly in its approach to enemy behaviour, traversal mechanics, and level flow.

The project demonstrates skills in Python game development, Pygame, object‑oriented design, game architecture, and user‑driven development.

## Requirements & How to Play
Python: Version 3.1.3

Pygame: Version 2.6.1

Download the project files and run main.py.

<b>Controls</b>

WASD — Movement

Space — Jump

J — Attack

K — Block

L — Interact

Hunted Horizon is currently unfinished, but all development progress—including analysis, design, algorithms, testing, and evaluation—is documented in my NEA project report.
